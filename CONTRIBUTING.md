# Contributing Guide

## Branching Workflow
- Create feature branches from `dev`
- Open pull requests into `dev`
- `main` only receives tested, stable merges

## Setup
- Frontend: `cd frontend && npm install`
- Backend: `cd backend && poetry install` or your chosen setup

## Commit Messaging
Use clear messages: `"Add X"`, `"Fix Y"`, `"Refactor Z"`.

## Pull Requests
- Keep PRs small
- Provide descriptions
- Link issues if any
